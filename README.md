# 心印共鸣预备：QQ 聊天记录提取并导入软件 Skill

这是一个面向 Codex 的本地工作流 Skill，用于在用户明确授权的前提下，将手机 QQ 已经通过电脑 QQ 保存的聊天备份恢复到隔离的 Android 模拟器，离线提取指定联系人的聊天记录，并转换为心印共鸣可导入的数据。

## 下载

下载仓库中的：

`心印共鸣预备-QQ聊天记录提取并导入软件.skill`

`.skill` 是便于分享识别的 ZIP 兼容压缩包，不是可直接双击运行的 EXE。

SHA-256：

```text
EC041BFC1046A4B7F7AA1B9583AF9AA36334151FBB6B4B6872E95ED95BE9D20B
```

## 安装

1. 把 `.skill` 文件扩展名临时改为 `.zip`。
2. 解压后得到 `qq-chat-backup-recovery` 文件夹。
3. 将该文件夹复制到：

   ```text
   %USERPROFILE%\.codex\skills\qq-chat-backup-recovery
   ```

4. 新建一个 Codex 任务；若 Skill 列表尚未刷新，重启 Codex Desktop。
5. 对 Codex 说：

   ```text
   使用 $qq-chat-backup-recovery，处理我已经备份到电脑的手机 QQ 聊天。
   ```

仓库中的 `qq-chat-backup-recovery` 目录同时提供完整、可审阅的源码。

## 用户需要准备什么

1. 使用 QQ 官方功能，把手机聊天记录备份到电脑 QQ。
2. 等待 QQ 明确显示备份完成，不移动或改名备份内部文件。
3. 告诉 Codex：备份绝对路径、目标联系人备注/昵称、自己的显示名、心印共鸣路径和本地 Ollama 模型。
4. 确认记录属于自己有权访问的数据，并授权创建隔离模拟器实例、安装官方 QQ、恢复备份和制作只读快照。
5. 登录、扫码、验证码和设备确认由用户本人完成；完成后告诉 Codex“已登录”。

## 安全设计

- 原始电脑备份保持只读，只在时间戳工作副本上解析。
- 默认只导出一个明确指定的联系人。
- 默认使用本地 Ollama，不上传聊天数据库、导出 JSON 或聊天正文。
- 禁止进程注入、Hook、内存扫描、凭据窃取、实体手机 Root、关闭杀毒软件或创建后门/常驻服务。
- 密码、验证码、登录二维码、令牌和数据库密钥不会写入脚本、日志或最终报告。
- 如果当前 QQ 版本只能依靠不安全手段提取，工作流会停止并说明原因。

## 适用范围

- Windows
- 电脑 QQ 已完成的手机聊天备份
- MuMu 等隔离 Android 模拟器
- QQ Android NT 消息数据库的已解密只读快照
- 心印共鸣与本地 Ollama

QQ、模拟器和数据库格式会持续变化。兼容性应以执行时的版本检查为准，不应使用本仓库绕过 QQ 账号安全或访问无权处理的数据。
